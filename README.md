# 地平线 6 · 本周值不值得做（附调校速查）

《极限竞速：地平线 6》的离线速查页。一个自包含的单文件 HTML，先回答「**这周季节赛值不值得做**」，再给「怎么调」：

0. **本周值不值得做** —— 本周奖励车**是否车展买不到**、稀有度、车展价；可在**本地**读游戏存档，比对「我有没有」
1. **当周季节赛** —— 每场活动的**游戏内车辆限制原文** + 推荐车 + 9 位调校码 + 奖励
2. **季节赛限定车** —— 从开服到现在的 18 周历史，含「按车型索引」（反复被指定的备车清单）
3. **各模式车辆榜** —— 14 个组别（公路 / 泥地 / 越野 × C~R）的上榜车辆与调校师

带搜索框、筛选、点击复制调校码，**零外部依赖**，离线双击即可用。

**在线版**：https://yaaaccc.github.io/fh6-tunes/

---

## ⓪ 值不值得做：判据是怎么定的

只问两件事，按顺序看：

| 判据 | 怎么看 | 结论 |
|---|---|---|
| **一、买不到** | 这台车的获取途径里**没有「车展」** → 这周不拿，之后只能靠抽奖碰运气或等复刻 | ★★★ 只能靠季节赛事 / 车房宝物 / 秘藏座驾 · ★★☆ 车展买不到，或档位是传奇 / 极限竞速特别版，或车展价 ≥ 100 万 CR · ★☆☆ 车展随时能买 |
| **二、我没有** | 读本地存档，比对车库 | 存档里**确认已有**的车 → 星级**下调**（重复车不值得再跑一趟）；**「未见」不做任何上调**——因为「未见」不等于没有 |

顶部那句结论会随读档结果**重算**：全都有 → 「本周可以跳过」。

### 读存档这件事，能读到什么、读不到什么

地平线 6 的**完整车库清单在存档里是加密的**（`C_ProfileData`），社区目前没有公开的解密实现，所以本页**不读加密内容**，只读存档里两处**不加密**的地方：

1. **顶层存档摘要**（顶层 `<uid>_<gid>.json` 里的 `SaveDescription`，base64 明文）——写明车库车辆总数、驾驶时间、经验值
2. **`Livery_<序号>` / `Tuning_<序号>` 目录名**——用的是**不加密的车辆序号**

所以它只能标出「**您涂装过或调校过的车**」，其余显示「未见」——**「未见」不等于没有**，只是这份存档没提供证据。想更准，就在车库把本周奖励车随便涂一下再扫。

> 存档全程在浏览器内读取，**不上传任何内容**，也不写入存档目录。

## 页面内容

| 标签页 | 内容 |
|---|---|
| ⓪ 值不值得做 | 本周奖励车卡片（星级 / 能否买到 / 稀有度 / 获取途径 / 车展价）+ 「读存档 · 本地比对」按钮 + 本周其余活动（奖励不是车）+ 判据说明 |
| ① 本周赛事 | 当周季节赛逐项拆解。黄色块是**游戏内限制原文**（如「皮卡和四轮驱动车 · B 600」），另有推荐车与调校码；底部附社区表的另一套方案 |
| ② 季节赛限定车 | 18 周可折叠全表（类型 / 活动名 / 限定车 / 调校师 / 调校码 / 奖励）+ 按车型索引 |
| ③ 各模式车辆榜 | 14 个组别共 660 条车辆记录，含竞争力、驱动、难度、轮胎、定位、调校师 |

**季节赛的车辆限制分四档**：

| 档位 | 活动类型 | 限制方式 |
|---|---|---|
| 🔴 必须用 | 每周挑战 | 必须**拥有并驾驶**指定那一台车 |
| 🟠 按类别 | 终极考验 / 季节锦标赛 | 按车辆类别限车 |
| 🔵 推荐 | 危险标志 / 测速区间 / 测速照相 / 计时赛 / 漂移区域 / 直线车友赛 | 游戏不限车，表里给现成方案 |
| 🟣 条件 | 照片挑战 | 限品牌或场景 |
| ⚪ 任意 | 每日挑战 / 寻宝 / 特技派对 / 收藏品 / 捉迷藏 / 淘汰之王 / 每月劲敌 | 任何车都行 |

## 数据来源

| 来源 | 用途 |
|---|---|
| [Nova's Autoshow](https://forza.nerdyderg.com/)（社区维护） | 车辆**稀有度**与**获取途径**（游戏本身不带这两个字段，由社区手抄）。经与 B站目录全量对账：稀有度 556/556 一致，「车展买不到」这一判据 154 台 vs 154 台、**分歧 0** |
| [B站小玩具「地平线六车辆数据库」](https://www.bilibili.com/toy/forzahorizon6/index.html)（作者 Dr.Hydra） | 中文车名、中文档位名、**车辆序号 `id`**（存档里 `Livery_<序号>` 要用它才能对上）。页面右上角的**「车辆数据库」按钮**即跳此页（新标签页打开、站外） |
| [腾讯文档《地平线6线上车辆调校推荐》](https://docs.qq.com/sheet/DYWZVRWR0dnh3aHhZ)（社区维护） | 季节赛限定车（18 周历史）、14 个组别的各模式车辆榜 |
| [vgover（电玩帮）](https://www.vgover.com/) 每季季节赛事攻略 | 游戏内**车辆类别限制原文**、推荐车、调校码 |
| [TheXboxHub](https://www.thexboxhub.com/) Festival Playlist 指南 | 交叉核对 |

抓取**免登录**（公开分享的页面与表格可匿名读取），脚本不需要任何 Cookie 或令牌。

> ⚠️ **可信度提示**：网络上流传的调校码有相当比例是编造或抄错的。本项目的做法是**多来源交叉核对**，并以「9 位码反查」验证；仍建议游戏内先验证。调校码与车型年份绑定，且会随平衡性补丁失效。
>
> ⚠️ **奖励车名是从攻略文案里抽的**，个别会有笔误（如把 `Dino` 写成 `Dion`）。这类词本页会标「**未能定位**」而不是硬凑一台车上去——宁缺勿错。

## 目录结构

```
FH6-Tunes/
├── FH6-调校速查.html      ← 主交付物（离线单文件版）
├── FH6-调校速查.md        ← 同内容 Markdown
├── docs/index.html        ← 站点版（GitHub Pages 服务此目录）
├── 一键更新.bat           ← 双击更新数据并打开页面
├── 手机访问.bat           ← 局域网访问（不依赖公网）
├── 使用说明.md            ← 面向使用者的详细说明
├── 更新日志.md            ← 每次运行的追加记录
├── scripts/
│   ├── fh6_lib.py         ← 抓取 + 解析（腾讯文档网格 / vgover 攻略）
│   ├── fh6_catalog.py     ← 车型目录（稀有度 / 获取途径 / 车展价）+ 奖励车匹配 + 「值不值得做」判据
│   ├── fh6_build.py       ← 生成页面
│   ├── update.py          ← 主入口
│   ├── test_catalog.py    ← 匹配器回归自测（改匹配逻辑后必跑）
│   └── serve.py           ← 局域网静态服务
├── data/                  ← 抓取原始数据与解析结果（JSON）
│   └── catalog.json       ← 车型目录缓存（默认 14 天有效）
└── 存档-旧版/             ← 早先的两个独立页面，内容已并入主页面
```

## 本地使用

**要求**：Python 3.8+（无第三方依赖，仅用标准库）

```bash
# 更新数据并重建页面
python scripts/update.py

# 只重建页面，不重新抓取（浏览器/机型目录也不联网）
python scripts/update.py --no-fetch --quiet

# 指定当周攻略文章
python scripts/update.py --set-guide-url https://www.vgover.com/news/<id>

# 换季后社区表尚未刷新时，每 5 分钟重试，最多等 60 分钟
python scripts/update.py --retry-min 60

# 只重建页面、完全不联网
python scripts/fh6_build.py

# 匹配器回归自测（改过名字匹配 / 判据后必跑，看是否还 0 漏匹 0 误匹）
python scripts/test_catalog.py

# 局域网访问（手机同 WiFi 打开）
python scripts/serve.py 8080
```

Windows 下直接双击 `一键更新.bat` 即可。

## 自动更新

季节赛每周四晚 22:30（北京时间）换季。定时任务在换季后抓取并重建页面；因社区表作者更新有延迟，脚本会检测「表是否仍停在上一周」并自动重试等待。

车型目录（`data/catalog.json`）默认 **14 天**过期后重新抓取；抓取失败时沿用旧缓存，不会因为社区站挂掉而生成不了页面。

更新后 `docs/index.html` 会同步刷新，**推送到本仓库即完成线上更新**。
