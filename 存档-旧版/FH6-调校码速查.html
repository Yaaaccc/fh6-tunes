④ 怎么用这些码

  1. 先按码对应的年份 + 完整车型买车（车展 CR 购买 / 车房宝物 / 抽奖等）。年份差一位就搜不到。
  2. 坐进这辆车 → 菜单 → 车辆 → 升级与调校 → 寻找调校 → 搜索。
  3. 输入 9 位数字（不要加空格），下载并安装。安装零件要花 CR，先看余额。
  4. 漂移类调校记得把变速箱设为手动、关 TCS / 稳定控制，效果才对。
  5. 码失效的常见原因：车型/年份不匹配、车辆是 Forza Edition 或 Welcome Pack 版本、作者已更新或下架、网络异常。

⑤ 避坑提醒

1. 网上大量「调校码」是编的。我就撞见同一台车在不同站点给出只差最后一位的码 （如 GMC Syclone 一处 832220934、一处 832220937）—— 后来在两个独立调校库里都只查到后者，前者可判定为抄错。
2. 明确标注「本文为虚构内容」的站点一律不能用。这类页面会整段编造分享码。
3. 卖金币/代练类网站上的榜单只能当线索，不能当依据；请以游戏内搜索结果 + 调校师 ID 为准。
4. 码是「车型锁」的，且会随平衡性补丁变化。9 位码搜出来能装上、性能分对得上，才算真的有效。
